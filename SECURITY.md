# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in VoteScot, please report it responsibly by emailing the maintainer directly rather than opening a public issue.

## Scope

VoteScot is a static site deployed to GitHub Pages. It does not store user data, use cookies, or process authentication. The quiz runs entirely in the browser. The primary security concern is the integrity of candidate data served to voters.

## Supported Versions

Only the latest version deployed to GitHub Pages is supported.
